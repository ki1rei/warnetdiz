# Warnet DIZ 🖥️

Website sederhana untuk mengelola aktivitas warnet, mulai dari sesi penggunaan PC sampai pencatatan transaksi.

## ✨ Fitur

### User

* Login sebagai user
* Melihat PC yang digunakan
* Melihat durasi penggunaan
* Melihat biaya penggunaan
* Melihat status sesi

### Admin

* Login sebagai admin
* Mengatur tarif per jam
* Memulai sesi user
* Melihat daftar user
* Melihat status PC
* Melihat statistik PC dan transaksi
* Melihat dan memvalidasi transaksi

## 🛠️ Teknologi

* HTML
* CSS
* JavaScript
* Tailwind CSS
* LocalStorage
